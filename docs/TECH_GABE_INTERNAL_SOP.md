# TECH GABE INTERNAL SOP

## 1) Browse Manuals
1. Open `/tech/manuals`
2. Search by brand/model/type
3. Select the target manual and click **Ask GABE**

## 2) Ask Manual-Scoped Questions
- Ask specific technical questions (venting, clearance, gas/manifold, startup)
- Confirm response includes selected manual context and page citation

## 3) Validate Answer Quality (quick check)
- Source type should be manual
- Cited manual must match selected manual
- Cited page should be present
- If not, treat as invalid for field use

## 4) Handle Bad/Weak Answers
- If answer says no verified evidence, verify the manual truly lacks the detail
- If answer is vague/generic, capture:
  - selected manual
  - question
  - answer
  - expected evidence/page (if known)

## 5) Report Missing Manuals / Missing Parts
- Report in internal feedback tracker with:
  - brand/model
  - missing manual URL (if known)
  - question that failed
  - screenshot or response payload

## 6) Escalation
- Safety-critical uncertainty (gas leak, vent clearances, wiring uncertainty): escalate to supervisor/manufacturer docs immediately.
